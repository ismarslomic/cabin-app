# Security policy

This is a personal project that runs on a single Raspberry Pi. Only the latest release is supported.

## Reporting a vulnerability

Please do not open a public issue. Report it privately with
[GitHub's private vulnerability reporting](https://github.com/ismarslomic/cabin-app/security/advisories/new).

Include what you found, how to reproduce it, and what you think the impact is. I will look at it as soon as I can
and will say so in the report when it is fixed. There is no bug bounty.
